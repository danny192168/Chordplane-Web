Setlist sharing

Send the set, not your whole library.

ChordPlane shares the running order you built: the songs, their keys, capo notes and position in the set. Your library, favorites and unpublished work stay on the phone.

What the other person receives

A shared set is a snapshot, not a live window into somebody else's device.

The songs in the set

Titles, artists, chord sources, keys, capo and tempo travel with the bundle so the receiving phone shows the same sheet.

The running order

Positions are preserved. Bandmates open the set in the order you intend to play it, without rebuilding anything.

Your library stays yours

Favorites, drafts, other setlists and unpublished songs are never part of the export.

Import is one tap

Scanning or opening a link brings the set into ChordPlane. Matching songs are reused instead of duplicated.

Sharing questions

  • What does ChordPlane share with bandmates?

    Only the song or set list you choose. The rest of your library is not part of the bundle.

  • Can I share without an account?

    Yes. QR codes, files and basic links work as a guest. Managed cloud links that can be revoked need an account.

  • Can a shared setlist be updated or revoked?

    Managed cloud links can be updated and revoked later. Recipients see the snapshot you published.

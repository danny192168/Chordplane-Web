Three steps

  1. Download the APK. It lands in your browser's downloads, like any other file.
  2. Open it and allow the install. Android will ask once whether your browser may install apps. That prompt is normal for anything that doesn't come from Play.
  3. Open ChordPlane. It appears in your launcher as ChordPlane. Later builds install straight over this one.

Minimum version is Android 7.0 (API 24). The APK is signed, so Android can verify that updates come from the same publisher.

Before you install

  • Will updating erase my songs?

    No. Installing a newer APK replaces the app but leaves its data alone, so your library and set lists carry over.

  • Can I share a whole set list?

    Yes. Open a set list and choose Share setlist to send every song as a QR code, a link or a .cpl file. Your library stays on your device; only the set you choose is shared.

  • Do I need an account?

    Not to use the app. Signing in is only needed to create share links you can manage and delete later.

  • Why does Android warn me?

    Because the file comes from GitHub rather than an app store. The warning is about the source, not about the app being unsafe.

  • Is there an iPhone version?

    Not yet. The Android build is the only one published so far.

  • Can I verify the download?

    Yes — the checksum link above gives you the SHA-256. Compare it with shasum -a 256 chordplane-latest.apk on a Mac or Linux machine.

  • Where do I report a problem?

    Open an issue on GitHub. Include your Android version if something misbehaves.
